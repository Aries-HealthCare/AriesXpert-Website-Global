# AriesXpert-Website-India

This is the primary clinical and SEO hub for Aries PhysioCare India, a division of Aries HealthCare International Pvt Ltd.

## Git Repository
**Origin**: `https://github.com/Aries-HealthCare/AriesXpert-Website-India.git`

## Core Features
- **AI Precision Recovery**: Data-driven insights for patient rehabilitation.
- **Localized SEO Hubs**: Dedicated city and area pages with expert registries.
- **Tele-Health Integration**: Free live consultations with clinical specialists.
- **Clinical Registry**: Vetted expert directory and transparent pricing protocols.
- **AI Anatomy Viewer**: 3D diagnostic visualization for patient education.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- ShadCN UI
- Three.js (Anatomy Visualization)
- GSAP (Cinematic Motion)
- Genkit (AI Core)

## Getting Started

1. **Initialize and Connect**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: AriesXpert India Hub with AI Diagnostics"
   git branch -M main
   # Use set-url if origin already exists
   git remote set-url origin https://github.com/Aries-HealthCare/AriesXpert-Website-India.git || git remote add origin https://github.com/Aries-HealthCare/AriesXpert-Website-India.git
   git push -u origin main
   ```

2. **Development**:
   ```bash
   npm run dev
   ```
